# MatchChayn

MatchChayn is an exclusive, modern dating and networking platform designed specifically for professionals. Whether you are looking for meaningful relationships or looking to expand your professional network, MatchChayn bridges the gap between career ambitions and personal connections.

## Overview

This repository contains the official frontend web application and landing page for MatchChayn. Built with performance and SEO in mind, it provides a seamless, highly responsive user experience. 

## Key Features

- **Exclusive Professional Network:** Connect with ambitious, verified professionals.
- **Dynamic Dual-Purpose Profiles:** Seamlessly switch between dating and networking modes.
- **Lightning-Fast UI:** Built on the Next.js App Router for instant page loads and optimal SEO.
- **Automated Waitlist & Newsletters:** Integrated queue systems for scalable user onboarding.
- **Responsive Design:** Beautiful, fluid interfaces that work perfectly on any device.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & shadcn/ui
- **Animations:** Framer Motion
- **Emails:** React Email & Resend (Hosted via Cloudinary)
- **Infrastructure:** Vercel, Upstash (QStash)
- **Data Integration:** Google Apps Script Webhooks

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository and install dependencies:
```bash
npm install
```

2. Set up your environment variables. Copy the example file and fill in your keys:
```bash
cp .env.example .env
```

3. Start the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
